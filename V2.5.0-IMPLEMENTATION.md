# Fish School v2.5.0 Implementation Guide

## 概述
v2.4.0 已完成后端基础设施（/tree API, 路径验证, 同步重启）。v2.5.0 要实现前端四栏布局：**共享库 | 我的共享 | 共享设置 | 鱼群成员**

## 整体架构

### 数据流
```
Panel (v2.5.0)
  ├─ LibraryColumn: useLibrary() → remote fish → FishTree component
  ├─ MineColumn: useSelfTree() → /tree for self → FishTree component  
  ├─ SettingsColumn: useMyCollections() → /collections → folder/project management
  └─ MembersColumn: useSchool() → status.peers → peer management
```

### 核心组件

#### 1. V3Text & Styles (~50 lines)
- Bilingual string dictionary for Chinese/English labels
- CSS grid layout: 4 columns with responsive minmax sizing
- Hover states, badge styling, row components

#### 2. Tree Utilities (~60 lines)
- `v3Icon(it)` — icon selector by file type / item type
- `v3Label(it)` — display label priority (title > summary > name > path > id)
- `v3Hay(it)` — searchable text from title/summary/name/path/tags
- `v3Tree(items)` — build nested folder structure from relative paths
- `v3Ago(iso)` — format relative timestamps (5m ago, 2h ago, 3d ago)

#### 3. ShareTree Component (~120 lines)
- Render grouped collections (folder/project/manual) with expansion state
- Support recursive directory nesting with lazy expansion
- Auto-expand everything when `search` query is active
- Per-item actions: preview, copy reference, visibility toggle (mine only), delete (mine manual only)
- Handles remote item preview lookup via peer.id or peer.name fallback

#### 4. FolderPicker Modal (~100 lines)
- Modal overlay with breadcrumb navigation
- Root view showing places (home, Documents, drive letters)  
- Directory listing with Up button, inline path input
- Recent workspaces list (from `/workspaces` endpoint) for project selection
- Confirm/cancel buttons to return selected path

#### 5. LibraryColumn (~80 lines)
- Filter remote fish from `status.peers` via `/library`
- Search box with debounced query
- Per-fish tree expansion (lazy-load /tree on first expand)
- Periodic refresh (15s when expanded, on every tab visibility change)
- Search triggers load of all online fish trees
- Render ShareTree component for each remote fish

#### 6. MineColumn (~70 lines)
- Render self tree via `/tree?fish=<myId>`
- Search support (same as LibraryColumn)
- Extra actions: visibility toggle, delete for manual items only
- Visibility shows "public" or "private" badge
- "Me" label via v3t('me') or fallback to 'me'

#### 7. SettingsColumn (~100 lines)
- Segmented control: folders | projects | manual
- List matching collections with: name, path (monospace), sync status, item count
- For each: buttons for edit, resync, visibility toggle, delete
- Edit mode: inline form with kind/name/path/visibility inputs
- Browse button opens FolderPicker → updates path field
- For projects: show recent workspaces as clickable chips (from `/workspaces`)
- Create form: blank when nothing selected, populate with chosen settings
- Create/save handlers post to `/collections` (POST for new, `/collections/update` for edit)
- Inline error display from API responses

#### 8. MembersColumn (~70 lines)
- "Me" card: avatar icon, name (editable), ID prefix, port, LAN status
- Version notice (reuse VersionNotice component if possible)
- Peer list: for each peer show dot, name, address:port, item count, remove button
- Add peer form: address input + Add button (opens on Add button click)
- Scan LAN button: calls `/scan`, shows result via toast or inline message
- Remove peer: calls `/remove-peer`, refresh via refresh()

#### 9. PanelV3 Main (~150 lines)
- Import/use useSchool() for status updates
- Set up state for: libGroups, myCollections, myTree, myTreeTick, previewItem, busy
- CSS injection via useV3Styles()
- Header: title, version badge, port, member count
- Four-column grid wrapper with column components
- PreviewModal integration for item preview
- Refresh/tick coordination: all mutations bump a `tick` state which columns watch

## API Contracts

### GET /tree?fish=<id>
Returns:
```json
{
  "fish": { "id": "peer-id", "name": "peer-name", "self": true/false, "online": true/false },
  "collections": [ { "id", "name", "kind", "itemCount", "visibility", "sync": {state, error, ...} } ],
  "items": [ { "id", "type", "path", "name", "title", "tags", "size", "updatedAt", "author", "isPublic", "excerpt" } ]
}
```

### GET /fs/list?path=<encoded-path>
Returns:
```json
{
  "path": "/current/abs/path",
  "parent": "/parent/abs/path or null/empty",
  "dirs": [ { "name": "foldername", "path": "/abs/path" } ],
  "truncated": false
}
```

### POST /collections
Request: `{ "kind": "folder|project", "name": "", "visibility": "public|private", "root": "/path" }`
Returns: `{ "collection": {...}, "sync": {...} }`

### POST /collections/update
Request: `{ "id": "", "name": "new-name", "visibility": "public|private", "root": "/new/path" }`
Returns: `{ "collection": {...}, "sync": {...} }`

### POST /collections/delete
Request: `{ "id": "" }`
Returns: `{ "success": true }`

### GET /workspaces
Returns: `{ "workspaces": [ { "path": "", "name": "workspace-name", "lastUsed": "ISO-date" } ] }`

### Existing /library, /delete, /set-visibility
Reuse as-is for managing and sharing items.

## Integration with Panel

In `client.js`, replace the old Panel function body with:
```javascript
function Panel({ t }) {
  // Keep old hooks: useSchool, rename, checkUpdate, etc.
  // ... existing validation and handlers ...
  
  // v2.5.0: delegate to new four-column workspace
  return h(PanelV3, { t });
}
```

The new PanelV3 function imports/uses the same `t` function, preserving host locale binding.

## Performance Notes

- Remote tree data caches per fish, refreshes every 15s while expanded
- Search triggers load of all trees; cap at 5000 items total
- Directory trees render lazily (recursive): expand only when needed
- Collection counts aggregate at render time (no caching needed)
